# EDAF90 Project

A web app which shows departures from Swedish bus stops and train stations on a dashboard. Data is fetched from [Trafiklab](https://trafiklab.se)

## API keys

A guide for fetching and installing the required API key is provided in the web app when it is running.

No environment variables are required.

## Running the app

### Installation

Install the dependencies:

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173`.

## Building for Production

Create a production build:

```bash
npm run build
```
